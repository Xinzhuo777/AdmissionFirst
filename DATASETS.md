# Datasets

The experiments use TPC-H SF1, TPC-H SF10, and the JOB 2013 IMDb snapshot.
The application workload uses synthetic data generated by the code. Prepare the
external files below before running the full experiment.

## TPC-H

Download the [TPC-H 3.0.1 tools](https://www.tpc.org/tpc_documents_current_versions/download_programs/tools-download-request5.asp?bm_type=TPC-H&bm_vers=3.0.1&mode=CURRENT-ONLY),
accept their terms, and build DBGEN using the included instructions. Keep
`dbgen` and its `dists.dss` file together. From the `code/` directory, set
`DBGEN_DIR` to that directory and generate the tables:

```sh
DBGEN_DIR=/absolute/path/to/official-tools/dbgen
ARTIFACT_ROOT="$(pwd)"
mkdir -p datasets/tpch/sf1 datasets/tpch/sf10
for sf in 1 10; do
  for table in c O L n; do
    DSS_CONFIG="$DBGEN_DIR" \
    DSS_PATH="$ARTIFACT_ROOT/datasets/tpch/sf$sf" \
      "$DBGEN_DIR/dbgen" -s "$sf" -T "$table"
  done
done
```

This creates `customer.tbl`, `orders.tbl`, `lineitem.tbl`, and `nation.tbl`
for each scale. Generate each scale in an empty directory and keep the standard
`.tbl` format.

## JOB / IMDb

Read the [CWI dataset notice](https://event.cwi.nl/da/job/readme.txt) before
using the 2013 snapshot. From `code/`, download and extract the five tables
needed for the experiments:

```sh
mkdir -p datasets/downloads datasets/imdb/csv
curl -fL --retry 3 https://event.cwi.nl/da/job/imdb.tgz \
  -o datasets/downloads/imdb.tgz
tar -xzf datasets/downloads/imdb.tgz -C datasets/imdb/csv \
  title.csv movie_companies.csv cast_info.csv kind_type.csv company_type.csv
```

Keep the original CSV encoding and escaping. The PostgreSQL process must be
able to read the files.

## File layout

The inputs should look like this under `code/datasets/`:

```text
tpch/sf1/{customer,orders,lineitem,nation}.tbl
tpch/sf10/{customer,orders,lineitem,nation}.tbl
imdb/csv/{title,movie_companies,cast_info,kind_type,company_type}.csv
```

Each name inside the braces is a separate file. Allow at least 50 GB for the
inputs and temporary PostgreSQL databases. The synthetic dataset configuration
is in `code/datasets/manifests/synthetic_saas_scales.yaml`.
